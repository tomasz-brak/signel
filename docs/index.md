# `signel` — Typst Waveform Embedding Package

**`signel`** is a native, OS-agnostic Typst package for embedding digital simulation waveforms defined in the **IEEE Std 1364-2001** Value Change Dump (**VCD**) and Extended Value Change Dump (**EVCD**) formats directly into Typst documents.

---

## Highlights

- **Pure Typst Engine**: 100% OS-agnostic (Linux, macOS, Windows, FreeBSD, WebAssembly in typst.app). Runs entirely within the Typst compiler with zero external binary or toolchain dependencies.
- **IEEE Std 1364-2001 Compliant**:
  - Full support for standard VCD traces (scalars `0`, `1`, `x`, `z`, binary vectors `b...`, real numbers `r...`).
  - Native support for Extended VCD (**EVCD**) generated by `$dumpports` with complete 23-character port directionality and driver strength decoding (`DUNZduLHXTlh01?FAaBbCcf`).
- **Rich Vector Rendering**:
  - Clean digital square waves for single-bit signals.
  - Hexagonal beveled envelopes for multi-bit buses with automatic value formatting (Hex, Decimal, Binary, ASCII, Raw).
  - High-impedance ($Z$) and unknown ($X$) logic state visualization.
  - Signal dividers and section grouping.
  - Vertical timing markers and shaded cursor intervals ($\Delta t$).
- **Custom Styling & Theming**:
  - Built-in themes: `default`, `dark`, `academic` (monochrome for papers), `nord`, `dracula`, `emerald`, `amber`.
  - Full customization helper `vcd-theme()` to tweak colors, strokes, dimensions, and typography.
  - Per-signal overrides (color, label alias, bus fill, format).

---

## Quick Example

```typst
#import "@local/signel:0.1.0": render-vcd, themes

#render-vcd(
  read("sim.vcd"),
  title: "Counter Timing Diagram",
  signals: ("clk", "rst_n", "count [3:0]"),
  time-step-width: 4pt,
  theme: themes.default,
)
```
